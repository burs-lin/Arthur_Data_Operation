# 字段识别模式参考(v2.0)

本文档说明 `excel-data-cleaner` 在清洗过程中如何识别并归一每一种字段。

## 1. ID / 编号类(含 `xxx号`)

- **匹配关键词**:
  - 英文:`id`、`编号`、`no`、`code`、`key`、`uuid`
  - 中文后缀:`工号`、`订单号`、`流水号`、`单号`、`票号`
  - **兜底**:任何列名包含 `号` 字都会被识别为 ID/编号类(如 `合同号`、`卡号`、`发票号`、`编号` 已经在列表里)
- **清洗动作**:
  - 转字符串、去前后空白
  - 单元格 number_format 固定为 `@`(文本),避免 Excel 把长数字变成科学计数法
- **异常**:主键列出现重复 → `[DUP_ID]`;主键列空 → `[MISSING_ID]`

## 2. 日期时间(DateTime,统一 24h)

- **匹配关键词**:`datetime`、`timestamp`、`date`、`time`、`日期`、`时间`、列名以 `_dt` / `_ts` 结尾
- **支持输入格式**:
  - `YYYY-MM-DD HH:MM:SS`
  - `YYYY-MM-DD HH:MM`
  - `YYYY/MM/DD HH:MM:SS`
  - `DD/MM/YYYY HH:MM:SS`、`MM/DD/YYYY HH:MM:SS`
  - `YYYY-MM-DD`(纯日期,时间归零)
  - `HH:MM:SS` / `HH:MM`(纯时间,日期归 1970-01-01)
  - **12h 制** `HH:MM:SS AM/PM`(自动转 24h)
- **输出格式**:`YYYY-MM-DD HH:MM:SS`(ISO 8601,24h)
- **异常**:超出 `[1970-01-01, today+1]` → `[BAD_DATE]`

> 强制 24h:不出现 `AM` / `PM` 标记;`01:30 PM` 自动转 `13:30`。

## 3. 月份(Month)

- **匹配关键词**:`month`、`月份`
- **支持输入**:`YYYY-MM`、`YYYY/MM`、`YYYY.MM`
- **输出格式**:`YYYY-MM`

## 4. 长文本(LongText,只 strip 首尾)

- **匹配关键词**:`desc`、`remark`、`备注`、`说明`、`comment`、`address`、`地址`、`note`、`notes`
- **清洗动作**:
  - **只**去除前后空白(包括换行/制表符/不间断空格)
  - **不**合并段落内部连续空白
  - **不**清除段落内部的空行
  - 超过 `max_length`(默认 500)则截断并追加 `[TEXT_TOO_LONG]`

> 这是 v2.0 的关键改动:之前会 `re.sub(r"\s+", " ", ...)` 把段落内的换行/连续空格合并成单个空格,现已修正为只 strip 首尾。

## 5. 金额(Amount)

- **匹配关键词**:`amount`、`money`、`price`、`金额`、`价格`、`fee`、`cost`、`salary`、`revenue`、`income`
- **清洗动作**:
  - 去掉货币符号 `¥` / `$` / `€` / `£` / `￥`
  - 去掉千分位逗号
  - 保留 2 位小数
  - 单元格 number_format:`0.00`
- **异常**:解析失败 → 写入空并记录 `[BAD_AMOUNT]`;超过 `out_of_range_abs` → `[OUT_OF_RANGE]`;Mean ± 2σ 之外 → `[STAT_OUTLIER]`

## 6. 数值(Number)

- **匹配关键词**:`count`、`qty`、`quantity`、`数量`、`age`、`score`、`ratio`
- **清洗动作**:转 `float`,保留有效位
- **单元格 number_format**:`0.##`
- **异常**:同金额列,含 `[STAT_OUTLIER]`

## 7. 手机号(Phone,中国大陆)

- **匹配关键词**:`phone`、`mobile`、`手机`、`tel`
- **清洗动作**:去所有非数字字符,保留 11 位数字
- **异常**:非 11 位数字 → `[BAD_PHONE]`

## 8. 邮箱(Email)

- **匹配关键词**:`email`、`邮箱`、`mail`
- **清洗动作**:
  - 转小写
  - 去空白
- **异常**:不匹配 `^[\w.+-]+@[\w-]+\.[\w.-]+$` → `[BAD_EMAIL]`

## 9. 布尔(Boolean)

- **匹配关键词**:`is_`、`flag`、`enabled`、`是否`、`active`
- **真值**:`true` / `1` / `yes` / `y` / `是` / `t` → `True`
- **假值**:`false` / `0` / `no` / `n` / `否` / `f` → `False`

## 全表字符串归一(作用于所有字段)

| 步骤 | 行为 |
|------|------|
| 1 | Unicode NFKC(全角→半角、`\xa0` 不间断空格 → 普通空格) |
| 2 | tab / `\xa0` → 普通空格 |
| 3 | 首尾 strip |
| 4 | 段落内部空行/连续空格**保留** |
| 5 | 邮箱统一小写 |

## 空值归一清单

| 字面量 | 说明 |
|--------|------|
| `""` | 空字符串 |
| `" "`、`"  "` | 纯空白 |
| `"\t"`、`"\n"` | 制表符 / 换行 |
| `"null"`、`"NULL"` | 字符串 null |
| `"None"` | 字符串 None |
| `"N/A"`、`"n/a"`、`"NA"` | 缺失占位符 |
| `"-"`、`"—"`、`"--"` | 短横线 |
| `"#N/A"` | Excel 错误 |
| `"\\N"` | MySQL NULL 占位 |

任何字段出现以上值,统一归一为空(写入空白单元格)。

## 全行重复检测(DUP_ROW)

若整行的所有列值与之前某行完全相同,标记为 `[DUP_ROW]`。

## 统计学异常值(STAT_OUTLIER)

对 `amount` / `number` 字段列,样本数 ≥ 10 时:

- 计算 `mean`、`std`
- 标记超出 `[mean - 2*std, mean + 2*std]` 的值
- 写入 `[STAT_OUTLIER]` 异常

可在 YAML 中调整 `stat_outlier_std_multiplier`(默认 2)与 `stat_outlier_min_samples`(默认 10)。

## 输出样式

所有 sheet(数据 sheet、`_CLEAN_REPORT`、`_ANOMALIES`)应用:

- **字体**:微软雅黑
- **字号**:9
- **颜色**:黑色 `#000000`
- **边框**:黑色细边框(thin);**整行/整列为空时不画边框**
- **表头**:加粗 + 浅蓝底色 `#D9E1F2`(前 N 行,N = 自动识别表头行数)

> **已废除**:`X.X万` / `0.0万` 这类数字格式应用逻辑已删除,本 Skill 不再对任何字段应用此类格式化。

### 术语定义

| 术语 | 定义 |
|------|------|
| 整行(如 1:1) | 该行所有单元格都为空(None 或空字符串) |
| 整列(如 A:A) | 该列所有单元格都为空(None 或空字符串) |
| 表头行 | 数据 sheet 中前 N 行(N 由 `detect_header_rows` 自动识别) |
| 表头列 | 第 1 列(A 列),从第一个有值单元格到最后一个有值单元格的范围 |
| 表头行数识别 | 扫描前 5 行,行内无任何数字则视为标题行,出现任意数字即视为数据行,停止 |

### 边框规则

- 有值单元格:黑色细边框
- 整行全为空:该行所有单元格不画边框
- 整列全为空:该列所有单元格不画边框

### 表头单元格自动合并(仅表头行/表头列)

| 规则 | 说明 |
|------|------|
| ① 向右合并 | 单元格右边为空,但右侧列整体不为空 → 向右合并 |
| ② 向下合并 | 单元格下边为空,但下一行整体不为空 → 向下合并 |
| ③ 多格合并 | 按①②迭代直至碰到非空单元格,支持 A1:B2 这种矩形合并 |

合并只发生在表头行(第 1 行)和表头列(第 1 列),数据区域不自动合并。
